# 星账本 iPhone 桌面小组件

小号与中号共用 `paper/scriptable/StarLedgerWidget.js`。小号显示主金额、预算、支出；中号增加预算剩余与左右分区跳转。主金额可以选净资产或总资产。默认推荐小号。

## 1. 更新云备份 Worker

已有坚果云备份的用户保留原来的 Worker 地址和四个 Secret：`DAV_FILE_URL`、`DAV_USERNAME`、`DAV_PASSWORD`、`SYNC_TOKEN`。

在 Cloudflare 的 **Workers & Pages → 你的 Worker → Settings / Builds** 连接本项目 GitHub 仓库，生产分支选 `main`，根目录保持仓库根目录，部署命令设为 `npx wrangler deploy`，然后部署本版本。也可以在已登录 Cloudflare 的本地仓库执行该命令。根目录 `wrangler.jsonc` 指向 `cloudflare/worker.mjs`；Wrangler 会打包它依赖的摘要、备份校验与账本计算模块。**不能只把单个 worker.mjs 粘贴进在线编辑器。**

本功能不需要 KV、数据库或额外 Secret。网页部署和 Worker 部署是两个独立步骤，网页更新不代表 Worker 已更新。若已有 Builds 集成，确认该次部署成功后再继续。

首次配置云备份：在坚果云新建 StarLedger 文件夹并创建第三方应用密码，将 ZIP 的 WebDAV 地址配置为 `DAV_FILE_URL`，邮箱填 `DAV_USERNAME`，应用密码填 `DAV_PASSWORD`，设置足够长的随机 `SYNC_TOKEN`。在网页 **设置 → 数据与备份 → 云备份** 填入自己的 Worker 根地址与同步令牌，保存并测试。需要自定义网页域名时设置 `PAGES_ORIGIN`。完整备份连接说明另见 README。

## 2. 网页准备

1. 打开 **设置 → 数据与备份 → iPhone 桌面小组件**。
2. 点 **立即备份并更新**。若出现云端差异，先核对并按现有流程处理。此按钮不会绕过冲突保护。即使账本没改，也会重新生成包含小组件摘要的 ZIP。
3. 点 **检查云端金额**，核对账本、账期、金额与备份时间。
4. 点 **生成连接配置 → 复制连接配置**。

生成的配置含只读令牌，不能下载 ZIP、覆盖备份或生成其他凭据。它仍能读取财务摘要，只给自己的设备使用。更改 Worker 的 `SYNC_TOKEN` 会撤销旧只读配置；网页云备份和 Scriptable 都需重新配置。

## 3. 安装 Scriptable 脚本

1. 在 App Store 安装 Scriptable。
2. 在网页小组件帮助中点 **复制脚本代码**，打开 Scriptable，点右上角 **＋**，粘贴，命名为“星账本小组件”。如果 Safari 不允许自动复制，页面会显示文本框，长按全选复制。
3. 回到网页复制“连接配置”，再运行脚本，粘贴 JSON。
4. 选择要显示的主账本，以及净资产或总资产。凭据保存在 Scriptable Keychain，脚本文件中不含凭据。
5. 脚本显示小号预览。再次运行可预览中号、刷新或重新配置。

也可下载脚本文件后通过文件共享导入 Scriptable；不同版本的共享菜单入口可能不同，复制代码是通用方式。

## 4. 添加到主屏幕

长按 iPhone 桌面空白处 → **编辑 / 添加小组件 → Scriptable** → 选择小号或中号 → 添加。长按组件 → **编辑小组件 → Script** → 选择“星账本小组件”。不需要填写 Parameter。

可以把同一脚本的小号、中号同时放到桌面比较。若要同时显示不同账本或不同主金额，复制脚本并使用不同脚本名称，各自运行配置。小号整张点击打开星账本网页；中号左侧打开网页首页、右侧直接进入“记一笔”。小号组件只允许一个点击区域（Scriptable / iOS 限制）。已有草稿时深链接不会覆盖草稿。

## 更新与金额口径

- 唯一数据源为坚果云最后成功保存的完整 ZIP。摘要在生成该 ZIP 时一并生成，不读取尚未备份的浏览器数据。Worker 校验 ZIP 与账本内容码后，只返回摘要。
- 自动备份沿用原流程：网页可见、没有编辑弹窗、数据稳定至少一分钟，且本次会话上传间隔至少一小时；存在云端冲突时暂停。关闭网页不会后台上传。可以点“立即备份并更新”主动触发。
- 请求到最新数据不等于 iOS 已刷新组件。脚本建议一小时后再刷新，实际调度由 iOS 决定，不能保证分钟级更新。卡片不显示备份时间；需要核对时，在网页点“检查云端金额”。
- 账期按备份时的本地日期和每月起始日计算，与网页正在查看哪个历史月份无关。跨账期未备份会显示“旧”及原月份。
- 总资产、净资产沿用账户校准、隐藏账户、是否纳入资产和汇率规则。预算和花销分别沿用现有规则：“不计预算”的支出仍包含在花销中。预算未设置显示“未设置”；零预算显示 ¥0；未知资产显示“待核实”，缺汇率显示“待换算”。
- 断网使用当前连接的上次缓存并标“离线”；401 / 403 不再显示缓存，要求重新配置。更换连接会隔离并删除旧缓存。
- 当前小组件接口限制 ZIP 和解压内容为 20 MiB，避免超出 Worker 和组件资源限制；手机只接收金额摘要，不下载完整 ZIP。

## 排错

| 现象 | 处理 |
| --- | --- |
| 接口 404 | 先确认 Worker 已部署新版；然后确认已有云端备份 |
| 接口 409 / 没有摘要 | 点“立即备份并更新”；旧版本 ZIP 没有小组件摘要 |
| 接口 401 | 重新保存正确的同步令牌；重新生成小组件连接配置 |
| 接口 403 | 网页来源未获允许时配置 PAGES_ORIGIN；脚本凭据失效则重新配置 |
| 备份未更新 | 确认自动备份已开启，保持网页可见、关闭编辑弹窗；或主动备份 |
| 组件金额没立刻变化 | 先在网页检查云端金额，再在 Scriptable 运行脚本预览；等待 iOS 调度 |
| 账本不在备份中 | 重新运行脚本，选取现存账本；不会静默切到其他账本 |

## 设计参考与限制

布局参考 [Apple Widgets HIG](https://developer.apple.com/design/human-interface-guidelines/widgets) 中天气、日历、股票组件的主数字层级、小号聚焦与中号分栏原则；使用与当前网页协调的纸白 / 深墨配色、玫瑰色点缀、Georgia 衬线数字与宋体，保留清晰的层级和留白。网页提供示意预览，精确字号、截断和 iOS 着色外观需在 Scriptable 真机验收。此实现不承诺提供原生 WidgetKit 的所有 Liquid Glass / 着色控制能力。

API 使用 [Scriptable ListWidget](https://docs.scriptable.app/listwidget/) 与 [Keychain](https://docs.scriptable.app/keychain/)。

开发验证：`npm test`、`node scripts/test-cloudflare-worker.mjs`、`node --test paper-tests/widget-worker.test.mjs`，以及 Chromium / WebKit 的 `paper-tests/widget-browser.cjs`。真机验收小号、中号、深浅色、长金额、断网缓存和跨月提示。

已有脚本更新：在网页复制新版脚本代码，覆盖 Scriptable 中同名脚本并运行一次；保留脚本名称会继续使用原 Keychain 连接配置。
