# Account icon sources

The account picker and account page use the same local icon catalog. Icons are bundled with the static site so selecting an account does not contact an icon service.

- WeChat, Alipay, Meituan, PayPal, Apple and Apple Pay: [Simple Icons 16.36.0](https://github.com/simple-icons/simple-icons), CC0 1.0. Brand names and marks remain the property of their owners.
- Chinese bank marks: [dingyong0214/bank-logo](https://github.com/dingyong0214/bank-logo), original 120 × 120 PNG files. The source repository does not publish an explicit license for the images; these are used as third-party identifiers, with no affiliation or endorsement implied.
- UnionPay / 云闪付: [Iconify Logos 1.2.18](https://icon-sets.iconify.design/logos/unionpay/), CC0 1.0. The icon identifies the UnionPay network; it is not the exact 云闪付 app icon.
- Douyin note mark: ByteDance’s [Semi Icons 2.104.0](https://www.npmjs.com/package/@douyinfe/semi-icons), MIT, `tiktok_logo.svg`. This is the shared note silhouette, not the colored Douyin app badge.

The bank set covers ICBC, ABC, BOC, CCB, Bank of Communications, PSBC, CMB, SPDB, CITIC, CEB, CMBC, CIB, Ping An Bank, CGB, Huaxia Bank, Bank of Beijing, Bank of Shanghai, Bank of Jiangsu, Bank of Ningbo, Bank of Nanjing, and WeBank.

Digital RMB has no verified exact app asset in this bundle; the picker offers a clearly marked generic ¥ badge. MYbank / 网商银行 has no verified asset and keeps the ordinary account icon or a user-selected Emoji. The 云闪付 entry uses the related UnionPay network mark, not the exact app badge.

Pinduoduo / 拼多多: the exact app mark was not found in the checked offline icon catalogs. The picker uses a clearly labeled generic red 拼 badge, not an official logo.
